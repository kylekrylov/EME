# EME — тестовые задания для Frontend-разработчика

## Стек

- Vue 3 + TypeScript + Vite;
- Vue Router для маршрутов страниц;
- Pinia для общего состояния;
- SCSS и CSS Modules для компонентных стилей;
- VeeValidate для валидации форм;
- ESLint с `@antfu/eslint-config` и Prettier.

## Структура

```text
src/
├── api/               # HTTP-клиент и контракты REST-ресурсов
├── assets/styles/     # глобальные токены и базовые стили
├── components/        # общие layout- и UI-компоненты
├── config/            # конфигурация внешних сервисов
├── constants/         # устойчивые значения приложения и маршруты
├── layouts/           # общие оболочки страниц
├── pages/             # самостоятельные задания и их локальный код
├── router/            # конфигурация маршрутов
└── stores/            # общие Pinia stores
```

Общие UI-компоненты импортируются именованно через публичную точку входа `@ui`:

```ts
import { UiButton, UiInput, UiModal } from '@ui';
```

Прямые импорты из `@/components/ui/...` не используем. Страницы импортируют компоненты из `@ui`, а внутренние зависимости UI-библиотеки — из безопасных именованных subpath-entrypoints вроде `@ui/primitives` и `@ui/button-icon`. Так единое правило импорта не создаёт цикл через корневой `index.ts`.

## Страницы

| Задание               | Маршрут            | Статус    |
| --------------------- | ------------------ | --------- |
| Таблица пользователей | `/users`           | завершено |
| Табы                  | `/tabs`            | завершено |
| Форма обратной связи  | `/feedback`        | завершено |
| Модальное окно        | `/modal`           | завершено |
| Infinite scroll лента | `/infinite-scroll` | завершено |
| Список задач          | `/todo`            | завершено |

Локальный mock формы возвращает успешный ответ с небольшой задержкой. Для демонстрации состояния ошибки используйте email `error@example.com`.

Таблица получает пользователей из `JSONPlaceholder /users`. Поскольку ресурс содержит только 10 записей и не предоставляет роль, статус и дату регистрации, API-слой детерминированно дополняет данные и формирует 60 уникальных демонстрационных строк для проверки фильтров, сортировки и пагинации 10/20/50.

## Команды

| Команда              | Назначение                                            |
| -------------------- | ----------------------------------------------------- |
| `npm run dev`        | запуск Vite dev server                                |
| `npm run build`      | проверка типов и production-сборка                    |
| `npm run type-check` | проверка типов Vue и TypeScript                       |
| `npm run lint`       | ESLint и проверка форматирования без изменений файлов |
| `npm run lint:fix`   | безопасное автоисправление ESLint и форматирование    |
| `npm run format`     | форматирование проекта с Prettier                     |

## Линтинг и форматирование

Основная конфигурация находится в [`eslint.config.ts`](./eslint.config.ts). Она построена на `@antfu/eslint-config` и дополнена договорённостями проекта: обязательными точками с запятой, установленным порядком импортов и правилами Vue из style guide. Prettier использует те же точки с запятой и переносит каждый атрибут компонента на отдельную строку.
